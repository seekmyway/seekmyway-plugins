# Security Policy

Please report vulnerabilities privately to **info@seekmyway.com**. Do not open a public issue for security problems.

- Official repository: https://github.com/seekmyway/seekmyway-plugins
- Official MCP endpoint: `https://agent.seekmyway.com` (`/plugmcp`, `/mcp`). Treat plugins pointing to any other domain as unofficial.
- Every release lists SHA256 checksums in `SHA256SUMS.txt`.
- Never commit your SeekMyWay API key. Keep it in an environment variable or your client's secret settings.
